Section 14 — The Three Rules That Never Change

Truth Model

Event log = truth (append-only, never modified)

AgentState = projection (derived from events, never stored as primary)

Checkpoint = optimisation (shortcut for projection, not truth)

Intent Before Effect

  1. ToolCallIntended written to log (with dedup_key)
  2. Tool executes
  3. ToolCallCompleted written to log

If crash between 1 and 3 → UnknownOutcome event → trigger tool's RecoveryPolicy → never silently re-execute

Trust Boundary

DATA_ONLY fragments can never appear in instruction regions of the prompt.

Enforced in ContextBuilder only — the single choke point. Nowhere else.

A label nothing enforces is decoration.

Execution Modes
REPLAY

Reconstruct from event log only — no model call, no tool call, ever. Same code, same log, deterministic.

RESUME

Reconstruct history from the log, then continue with new durable steps. Real calls allowed.

EVAL

New code version. Recorded model and tool responses stand in for real ones. No network. Entering against a production log requires an explicit flag.
