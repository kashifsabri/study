

## Like I'm 10

Think of a **robot vacuum**.

- It **looks**: "I bumped into a chair."
- It **thinks**: "I should turn left."
- It **does**: it turns left.
- Then it **looks again**, and repeats.

It keeps going **until the floor is clean**.

Nobody tells it every single move. It decides by itself, one step at a time, based on what just happened.

**That's an agent: something that looks, thinks, does, and repeats until the job is done.**

---

## Simple technical version

An agent is a program that:

1. Has a **goal** ("clean the floor", "fix this bug", "answer this question").
2. **Decides its next step by itself**.
3. **Does** that step (uses a tool).
4. **Looks at the result**.
5. **Decides the next step based on that result**.
6. Repeats until the goal is done, or until it runs out of time/money/steps.

The most important point:

> **In an agent, the AI decides what happens next. Not the programmer.**

If the programmer already wrote every step in advance, it's not an agent. It's just a script.

### What's inside an agent vs outside

```
INSIDE the agent              OUTSIDE (the "world")
- the AI model (the brain)    - files
- the loop (keeps it going)   - websites
- its memory of this task     - APIs (other programs)
- the rules and limits        - the user
```

The agent **reads** from the world and **does things** to the world. The line between inside and outside is called the **boundary**.

### 5 things every agent has

|Property|Simple meaning|
|---|---|
|Goal|It's trying to finish something|
|Decides by itself|Picks its own next step|
|Reacts|Changes plan based on what it sees|
|Many steps|Doesn't stop after one reply|
|Limits|Has a max time / cost / number of steps|

## Real-life examples

### How Claude does it

When you asked me for a note file:

1. I decided: "I need to create a file." → I asked for the file tool.
2. The system created the file and told me "done."
3. I saw that and decided: "Now send it to the user."
4. The system sent it.

**I never did anything myself.** I only _asked_. The system around me actually did it. That's the key idea.

### How ChatGPT does it

In ChatGPT's agent mode, you can say "find me 3 cheap flights to Delhi." It opens websites, clicks, reads results, and tries again if something fails. It **asks you before** doing anything serious, like paying.

### In real products

- **Claude Code** (a coding agent): reads your code → changes it → runs the tests → sees what failed → fixes → runs tests again. It repeats until tests pass.
- **GitHub Copilot coding agent**: you give it a bug ticket, it works on the code by itself, then opens a pull request for you to review.

## In Agent Core

We are building exactly this "system around the AI."

- The AI only **suggests** an action. We call that an `ActionProposal`.
- **Our code** decides whether to actually do it.
- The result comes back to the AI as **information only**. It can never give orders.

We define these pieces in **P1** and build the tool part in **P4**.

## Say it to yourself

> "An agent is a loop. The AI picks the next step based on what the last step returned. The AI only suggests. Our code decides what actually runs."

---

## Common mistakes

- Calling every AI chat app an "agent." A chatbot that just replies is not an agent.
- Thinking the AI model _is_ the agent. The agent is **the AI + the loop + the tools + the rules** together.
